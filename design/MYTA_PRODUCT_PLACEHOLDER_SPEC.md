# MyTA Product Evidence Placeholder Specification

Use these placeholders only during internal concept development.

## Required placeholders

### 1. Instructor assignment setup

Label:

`Instructor assignment setup`

Show only neutral structural regions:

1. Assignment title
2. Course materials
3. Learning goals
4. Support rules
5. Checks for understanding
6. Save or publish action

Do not invent detailed settings or claims.

### 2. Student guided assignment work

Label:

`Student guided assignment work`

Show only neutral structural regions:

1. Assignment prompt
2. Student response area
3. Guided-support panel
4. Attempt, explain, check, revise cues
5. Final-response responsibility

Do not show an AI-written final answer.

### 3. Instructor learning signals

Label:

`Instructor learning signals`

Show only neutral structural regions:

1. Difficult concepts
2. Recurring misconceptions
3. Question-level patterns
4. Students who may need support
5. Possible instructor actions

Do not include fake percentages, grades, names, or outcomes.

## Visual treatment

1. Neutral light background
2. Thin gray structural lines
3. Minimal brand accent
4. Clearly marked as an internal placeholder
5. No fake logos or user identities
6. No production use
7. Replace before final website approval
